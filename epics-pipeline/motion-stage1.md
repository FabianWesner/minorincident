# Stage 1 motion integration

Main merged at start (6f856fa), then the explicitly authorized outbreak2 landing (16c878a, main bc7e801). No skinned meshes or new dependencies are adopted. Mesh2Motion remains an evaluation candidate pending PO review.

Behavior/navigation supplies desired movement through unchanged `Npcs.move/moveStep` APIs. Serializable fixed-step response state bounds acceleration (6 m/s²), jerk (48 m/s³), heading speed (4.5 rad/s) and angular acceleration (12 rad/s²). Infected pursuit, wandering, migration, civilian/pet/escort/corgi movement and individual flock positions consume this response. Authored combat leaps/charges remain impulse exceptions to preserve their windup/hit timing. Actors without new movement intent brake after mission behavior, before collision-safe separation. Actual resolved displacement publishes speed/distance for gait phase. Collision, crowd overlap correction, grabs, knockback, death and teleport remain authoritative exceptions to the motion limits.

Click navigation uses the response for acceleration, braking and arrival, retains acceleration pressure when a capsule sweep clips movement, and slows at route corners. Rounded-corner route departure finds reachable grid cells instead of trapping a valid circular capsule in square grid dilation. A ground-level navigation sweep prevents coasting into conservative obstacle corners; elevated support is resolved by the 3D capsule because the grid has no height. Adaptive support clearance (5 mm resting, 10 mm raw moving, 20 mm navigation/raised support) fixes repeated flat-floor autostep and raised-paving stalls while preserving authored rest height. Raw keyboard 36/54 m/s² response, 720°/s turning and authoritative one-tick aim remain required by E04; the hero regression specifically measures click navigation. Render orientation uses quaternion slerp and bounded hero presentation turning. NPC position/heading uses snapshot interpolation and quaternion slerp; gait/fade clocks interpolate distance/time without feeding render state back into simulation.

Migration uses non-overlapping hexagonal lanes, tangent prediction and bounded tracking instead of a compressed spiral that continually triggers hard separation. Its original 150-agent timing, 4.5 m arrival envelope and subsequent movement tests pass. Separation caches radii and limits neighbor searches to possible contacts, retaining the existing three collision passes.

Crowds retain one instanced draw per existing batch. Clip changes freeze the last displayed part palette into an outgoing atlas row and crossfade for 200 ms, preserving interrupted transitions. The shader skips outgoing texture fetches after a fade. Static part flags share one vec4 attribute and fade metadata shares the tint attribute, fitting WebGL2's 16-location minimum in the production shaded/normal path. Paused same-tick teleports reset interpolated snapshots instead of retaining an old pose. Civilians preserve outbreak collapse/stagger/rise timing and gradual eye glow; infected preserve the independent rise handoff and pooled metadata reset. Escorts use mixer fades and corgi gait already uses mixer fades. Hero gait follows actual displacement during braking, with 200 ms attack-to-locomotion/base fades. Existing planted-foot retargeting also covers infected-run/shamble.
