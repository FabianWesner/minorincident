# Look development

`npm run look:capture` builds production, starts an isolated preview on 3306, and captures V1–V6 with seed 1 and paused simulation. Desktop: 1600×900/high. iPhone portrait: 390×844/low, DPR 1. It writes twelve PNGs, six comparison sheets, capture metadata, a reviewer rubric and a blank scoring template to gitignored `test-results/look-round/`. References are style targets, not matching locations. The supplied local mockup and PO Bruno image must exist; they are never committed.

In a worktree references default to the main checkout. Overrides: `LOOK_MOCKUP=/path/mockup.png LOOK_BRUNO=/path/bruno.webp`. `E2E_PORT=3316` selects another isolated preview port. `LOOK_SKIP_BUILD=1` uses an existing dist. `LOOK_URL=https://… npm run look:capture` targets a deployed production build without building/starting a server. `LOOK_OUTPUT=test-results/look-round/round-2` preserves rounds. All browser runs use the machine-wide e2e lock and a headless native-GPU Chromium on macOS. Only one game page runs at a time.

`npm run look:score` regenerates sheets and review files from existing captures. Give `reviewer.md`, all six sheets and original PNGs to an independent reviewer. Fill a copy of `scores-template.json`, documenting evidence and gaps for both tiers. A paused still cannot prove motion: supply a live review/clip and record it in `motionEvidence`, otherwise leave motion null. Paused capture counters are diagnostic, not FPS measurements. Use the separate E18 200-infected fixture for performance.

Delete generated screenshots after review; retain only needed metric/review JSONs. Keep `ref/` source images.

Open any production/deployed build with `?lookdev` to load L1 and show the existing Tweakpane. Expand light/shadow, fog, post, nature or palette folders; edits update persistent renderer uniforms while playing or paused. Viewpoints/time includes V1–V6, pause/step, quality and fixture controls. Export downloads `world-look.patch.json` with `{version:1, worldLook:{…edited values}, palette:{…edited swatches}}`. Reset restores checked-in values. The patch can be validated with `validateLookPatch` from `src/data/lookPatch.ts`. The orchestrator applies `worldLook` fields to `src/data/worldLook.ts` and palette fields to the palette source owned by r1-grade, then commits/rebuilds. No browser write commits source or changes gameplay saves.

`GameView.look.nodes` contains stable TSL uniforms for every look token; `GameView.setLook(patch)` validates and updates them, then refreshes lighting/palette/post/dressing. `Materials.look` exposes the same state to foliage/ground shaders. Grass density is capped by current allocation (28 high / 5 low blades/m²); foliage density removes a fraction of authored placements (0–1), and foliage height is relative placement scale. These controls retain the quality-tier budgets. Palette swatches update `Materials.texture` in place; existing baked vertex-colour props need r1-grade's shared-palette migration before every prop follows those swatches. Grass/root/tip, foliage tints and ambient leaf/petal/dust/bird colours already use live nodes. DOF stays off on low quality.

Performance proxy: `E2E_PORT=3306 sh tools/e2e-lock.sh npx playwright test tests/perf/look-tools.spec.ts --project=chromium --workers=1` records desktop/portrait p95 with 200 infected, checks E18 geometry budgets and writes JSON alongside the captures. This is headless mobile emulation on the Mac GPU, not physical-phone or WebGPU evidence.

The `perf-horde-200` debug fixture deliberately retains 200 simulated actors on both render tiers. Ordinary low-quality scenarios keep their normal 100-actor cap.
