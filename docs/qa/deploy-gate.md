# Deploy gate (PROD batches)

The orchestrator runs this on `main` before every PROD deploy (PO rules 10-07 / 10-09; long bot batteries are not part of it).

1. `npm run typecheck`, `npm run lint`
2. `npm run test:unit` (Hetzner: `sh tools/remote/run.sh $PWD -- npm run test:unit`). Since 2026-10-13 it includes the static QA guards:
   - `tests/unit/assets/lod-fidelity.test.ts`: every static prop/building/vehicle LOD against LOD0 (extent, silhouettes, vanished materials; backlog in `lod-fidelity.baseline.json`).
   - `tests/unit/levels/decoration-surface.test.ts`: drawn decorations only on soil, every district and tier.
   - `tests/sim/world/support-seams.test.ts`: no seam in raised walkable supports, every district.
3. `npm run build`; functional smoke runs on Hetzner through `tools/remote/gate-browser.sh`, with native WebGPU smoke retained locally. Full unit, sim and `tests/levels` sweeps also run on Hetzner, at most four Vitest workers.
4. Scene Lab for the touched areas, **both quality tiers and both zooms**: `npm run scene:matrix` (WebGL2 on Hetzner; props, seats, hand props, peds, corgi, Grove areas), then `npm run scene:matrix -- --backend webgpu --out test-results/scene-catalog-webgpu` on the Mac plus `npm run scene:catalog -- --matrix --filter '<area>*'` for other touched areas (L9 crash site: `--filter 'l9-crash-*'`; L9 drive/damage/handover QA: `--filter 'qa-l9-*,l9-enc-*,veh-apc-*,area-l9-*'`, on both `--backend webgl2` and `webgpu`; night route read E31-AC16 / L10 R1-R6: `--matrix --filter 'night-read-*'`, nav contrast gate (typical >= 2.5, floor 2.0), see scene-lab.md "Night navigation contrast"). Open the sheets of both tiers. L10 cure-* scenes also gate `lodPlaceholderFramesMax: 0` (no placement drawn from a coarser stand-in mesh than its LOD band); `--throttle 4` slows the CPU to expose load-dependent races, and `tools/qa/lod-pop-probe.ts --walk` samples `placeholderDraws` while walking a streamed level.
5. Browser e2e (functional rows: `npm run test:e2e -- --retries=1 <filters>` on Hetzner, one SwiftShader worker; WebGPU rows: local `tools/e2e-lock.sh`, at most two workers; Playwright path filters are regexes on the full path, so level specs need `levels/`): `levels/L1.spec levels/L2.spec levels/L4.spec l4-po-round l4-cellar-guidance l4-plaza-movement l4-barricade-prompts cellar-position l4-blank-viewport webgpu-canvas respawn-bat input-mouse crowd-visible-outbreak menu-10-levels` (10-14: 90 tests); for vehicle/ride changes `tests/e2e/levels/l4-bus-ride-smooth.spec.ts` (all 17 configs: both tiers, both backends, 60/120 Hz, uneven 120 Hz, 30 Hz, uneven phone cadence).

Details and the reasoning behind each guard: `docs/tools/scene-lab.md`, section "Quality x zoom matrix".


## GPU offload and admission (2026-10-18)

The orchestrator entry point `epics-pipeline/gate-browser.sh` mirrors the versioned `tools/remote/gate-browser.sh`. It fails on any gate failure. WebGL2 Scene Lab catalogs are routed through `tools/remote/run.sh` by `tools/remote/scene.sh`; trailing `--backend` and `--out` overrides are honored. Remote builds use the synced worktree, preview on a private port, and SwiftShader. `index.md`, `index.json`, sheets and individual row results are copied back even when scene gates fail. Keep remote WebGL2 and local WebGPU output directories distinct. `--list` only lists scenes locally.

`npm run test:e2e` runs functional `tests/e2e` on Hetzner. It excludes WebGPU, `@perf` and `@gpu` titles; the browser gate retains the selected WebGPU rows and WebGPU smoke on the Mac. Native `@gpu` look/grade checks use quiet-run because their browser is uncapped. Per-file Metal overrides are normalized to SwiftShader by the shared fixture on Linux. Remote timings are not native E18 frame-time evidence. Timing/perf, native look checks and WebGPU remain reference-Mac checks; no budget or visual threshold changes.

On the Mac, every browser command uses `tools/e2e-lock.sh` (opaque wrappers declare `E2E_UNITS`). Capacity is hard-capped at two even if `E2E_SLOTS` is larger. Before admission, `tools/mac-gpu-guard.py` samples WindowServer CPU time over ten seconds and waits above 60%, on a missing/restarted WindowServer sample, or when existing headless browser roots plus the requested capacity exceed two. Renderer/GPU subprocesses do not count as browsers. This protects admission; it cannot guarantee that macOS or a process launched outside the wrappers will never hang.

Uncapped Scene Lab probes require `tools/perf/quiet-run.sh`; the shared Playwright worker policy rejects uncapped launch flags outside it. Quiet-run reserves all legacy slots, runs one timing batch for at most 20 minutes, and terminates only its own process group on expiry. Release between batches and give other lanes an opportunity; a shared one-minute cooldown prevents quiet batches from chaining back to back. Stop waiting after 30 minutes and report unmeasured coverage. Every lane uses unique `E2E_PORT`/`SCENE_PORT`, never 3300. Browser automation stays headless.

Routing changes are exercised by `gpu-offload-courier` in the matrix catalog, with unchanged E18 low-tier draw/triangle bounds, no undrawn frames, and no console errors. Inspect game-camera sheets at high/low quality and zoom 1/0.5 on both backends (the matrix also retains zoom 1.5). See [GPU offload evidence](../reports/gpu-offload/README.md) for actual run results and limits.
