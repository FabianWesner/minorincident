# L1 asset integration

Base integration: `4a18c3f`. Follow-up merges main (`64bb466`, integrate-m3) once. The manifest merge uses recursive field-level three-way resolution and retains all 275 entries. Both viewer APIs and both validators' contract checks are retained; the removed LOD byte-ratio gate remains absent.

Existing Blender exports are processed by `tools/assets/optimize.ts` / `optimizeExports`: normalize orientation/metres, preserve named contracts, join static parts, quantize and meshopt-compress. No detailed models were rebuilt or remodelled. Each model has LOD0/1/2. Corrected low tiers are saved as supplied `assets/<id>/model.lod*.glb` exports so the merged pipeline can reproduce the validated geometry. Aliases now use their canonical source folder's supplied tiers with their own normalization. The original source `model.glb` files are unchanged.

Pallet tiers are 1012/156/14 triangles; plank-stack tiers are 2412/204/78 triangles. Lower tiers retain complete planar surfaces from the authored wood meshes: pallet LOD2 keeps top slats and bottom support faces; plank LOD2 keeps horizontal board faces and exterior surfaces. This avoids the disconnected triangles produced by aggressive unconstrained simplification and meets the density budgets. Reproduce runtime exports with `npm run assets:optimize -- <id>`. Portraits are deterministic CPU Blender renders of the existing head meshes, generated by `tools/assets/render-l1-portraits.py` through `experiment/tools/blender_run.py`.

## Blood decals

`decal.blood-splats`, `decal.blood-pool`, and `decal.blood-trail` are integrated 256px transparent PNGs. `python3 tools/assets/generate-blood-decals.py` deterministically generates dark red organic shapes. The registry creates a two-triangle ground quad for each texture; the validator checks dimensions and painted/transparent pixels. No redundant GLB LOD chain is needed for a two-triangle decal. The existing instanced VFX ground pool samples the same registered textures for hit splats, kill pools, and wounded trails, retaining gore mode behavior and disposing textures with the pool. No requested L1 asset remains missing; substitutions above remain explicit.

Merged compression also brings the previously oversized L1 LOD0 delivery files within validation budgets. Source semantic names are retained across tiers.
