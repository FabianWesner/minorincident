# L1 asset integration

Base: main d899e55 (merged once at start; already current). The separate art-integration lane is not merged into this base. This commit deliberately changes only its 30 owned manifest entries. Merge art-integration for the remaining previously integrated L1 art and its distance-LOD runtime wiring.

Existing Blender exports are processed by `tools/assets/optimize.ts` / `optimizeExports`: normalize orientation/metres, preserve named contracts, join static parts, quantize and meshopt-compress. No models or source GLBs were rebuilt or remodelled. Each model has LOD0/1/2. The two small slatted props retain their authored LODs: pallet 1012/276/228 triangles; plank-stack 2412/780/460. Their lower tiers exceed the approximate density ratios but remain tiny in absolute terms. A trial at .12/.03 either lost support height or rendered scattered triangles; it was rejected in screenshot review. No shared optimizer change is shipped. Reproduce with `npm run assets:optimize -- <id>` for the model's manifest source; alias entries share the listed real asset's runtime files. Portraits are deterministic CPU Blender renders of the existing head meshes, generated by `tools/assets/render-l1-portraits.py` through the main checkout's `experiment/tools/blender_run.py`.

## Integrated

- Maple Hardware; male/female civilians; white pickup, green sedan and green SUV; shopping cart, sofa, pallet, plank stack.
- House B, House C and Joe's Diner: supplied LOD2s replaced by `.03` simplification of the existing detailed model. Contract validation now passes.
- Crawler: legless authored model keeps its empty shin/foot contract nodes. Those four empty nodes are no longer declared as separately animated meshes. All visible joints and seven generated stump caps remain validated.
- Maple's roof/interior/hinged door names are protected through every optimization tier.
- Five existing SVG action icons (bat, crowbar, machete, kick, fists) are marked integrated and used by the existing HUD registry.
- Three 256px transparent head portraits, rendered from survivor/corgi art, replace HUD emoji/dot faces. Image-only manifest entries validate their shipped images rather than nonexistent GLBs.
