## Reproduction

Rebuild each exterior with `npm run assets:build -- <id>` (pharmacy, supermarket, gym, basement-cellar). Refresh selected static bakes/collision and generated physics/light tables. `tools/roof-audit/sweep.ts` inventories actual runtime files and transformed level layouts. Run `capture.ts before`, `capture.ts after`, then `catalog.ts` through `tools/e2e-lock.sh` with a private `SCENE_PORT`; before reads original commit `5a9d2682` from Git (override with `ROOF_BASELINE` if needed). Both capture inventories record camera state and console errors. Never use a headed browser.
