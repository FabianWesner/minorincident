The baseline uses the production build from a110323bc, headless native Chrome/Metal, the existing 390×844 phone profile and unchanged 4× CDP CPU throttle. Optional CDP sampling surrounds the existing defence, horde and rescue measurement windows. Sampling is diagnostic; final acceptance uses an unprofiled run through `tools/perf/quiet-run.sh`.

The 8.667-second defence profile attributes 3,114 ms to renderer call stacks (35.9%), 1,135 ms to the civilian crowd (13.1%), 695 ms to pose/contact solves (8.0%), 547 ms to shadow updates (6.3%), 269 ms to camera occlusion queries (3.1%), and 45 ms to GC (0.5%). Categories overlap: pose/contact work belongs to the crowd and shadows belong to rendering. Render submission/uniform packing dominates; skinning, UI and GC do not dominate this sample. `footFrame` alone has 186 ms self time, the largest named application helper in the defence self-time list. Horde weather updates account for 346 ms of its 8.404-second profile, including 104 ms in footprint rasterization.

The change reuses oriented footprint frames for static placements, rejects distant placements before computing their frames, computes each nearby footprint once for the lens samples, and removes temporary slab-test arrays. Weather rasterization clears only previously touched rows and retains row comparison data rather than copying the entire 4 MiB texture each update. The inherited paused-camera cutaway snap was removed after a before/after capture exposed its first-frame visual difference. The haze-instancing experiment is not included.

Raw CPU samples are in `defence-phone.cpuprofile.gz`, `horde-phone.cpuprofile.gz`, and `rescue-phone.cpuprofile.gz`; `profile-summary.json` contains self/inclusive samples with original bundle locations. Baseline frame p95 is 31.8/33.9/34.6 ms (defence/horde/rescue); these diagnostic values include sampling overhead and use this worktree’s gameplay base, which differs from the later l3-blvd-3 handoff build. The profiler instrumentation changes no assertion, scene population, budget, camera or throttle.
