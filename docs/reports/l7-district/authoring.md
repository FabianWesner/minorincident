# L7-D1 authoring and handoff

`levelSevenLayouts` starts from `levelFiveLayouts`, explicitly retains W5 placements/colliders to `maxTier: 6`, and expires the underground concourse, rescue cues, machine-gun nests and the east fence. Every original hero transform, scale and foundation footprint remains exact. W5 assets and the source D-FAIR layout are unchanged. Seven W6 shells are cut from the corresponding W5 LODs; source hashes and face counts are in `geometry.json`. No replacement building panels or boxes are authored.

Rebuild with `/Applications/Blender.app/Contents/MacOS/Blender -b --python tools/l7/build-w6.py`, then `... -b --python tools/l7/build-ground.py`, then `npx tsx tools/l7/optimize-w6.ts`. Raw W6 models live beside their W5 sources; delivery GLBs use the existing optimizer, meshopt and quantization. The church tower is retained as a recognizable landmark; the nave loses another roof/facade section. All original palette, sockets, dimensions and LOD caps are validated without exceptions.

The exact L6 `night-exit` anchor `[273, 3.9, 15]` is shared. A narrow eastern extension descends in 15 cm terraces to the existing city, with Harbor and Lakeshore branches; only the east boundary fence expires. Northgate reuses `int.metro-exit`. The rocket wreck uses the S2 offsets; the retained pickup uses the actual 3.9 m surface. `installL7Dressing` installs the existing arsenal/pickup hooks and 22 persistent E27 fires with smoke; the existing light and effect pools enforce caps. W6 adds five military wrecks plus the pickup truck to retained W5 wreckage, four extra collapsed facades (nine total) and four ruined road segments. Both nav branches and the rocket approach are checked in the district unit fixture.

`compositions.L7` and the SimWorld layout/render hooks expose the district to subsequent lanes. The night preset is the existing `L6` preset; light wind/ash uses E28's preset. D2 owns corridor/bus placement, final route endpoints and wider pair coverage; encounter, follower, bus departure and complete campaign tests belong to E/Q lanes. D1 covers the district/asset parts of AC09/10 and exit/wreck placement of AC04, not the whole epic.

Scene Lab accepts `layout.level: "L7"`; its district crop retains the W6 ground layer. DistrictView registers ground meshes from every baked layer, so vehicle resting probes see the new elevated paving. Fire fixtures rest on the same sim surface. These fixes also keep isolation captures representative of runtime geometry.

Review uses the unchanged plaza pair pose, W5-left/W6-right game-camera shell scenes for all seven buildings, and a moving Northgate courier on high/low. Existing W5 plaza static intersections are inherited (the collapse kit intentionally overlaps frontages); they are reported, not hidden by a changed tolerance. Actor clipping/visibility remain separately gated. Full E29 completion, final-horde and skyline judgments require later lanes.

The runtime asset loader now uses the existing declared `decayDimensions` for variant LOD bounds, matching the asset validator. This prevents valid town hall/church ruins from falling through to LOD0 because of the intact building height. The original tolerance remains exact; the registry regression also verifies that malformed variant geometry still falls back.

The two authored rectangle areas share the exact stepped polygon footprint with the NPC navigation mask (a grid equivalence test includes boundary points). This retains the original reachable world while avoiding repeated polygon-ray work for every infected steering probe. L7 uses the existing shared instance capacity and near-view staged preparation; close low-tier assets stream through the existing loader. Non-world dressing uses the same instance capacity; L7 low skips dressing shadow draws, matching the existing low prop policy. The performance API exposes compact infected/effect counts so the timing fixture does not clone the world/render debug snapshot at 10 Hz.

Low W6 uses a 256² footprint mask over the same 16 m window and lifetime; other levels retain their existing 1024² mask. The four bilinear sub-samples are evaluated without per-texel iterator allocations. Low W6 omits the city-wide moon shadow pass while keeping the palette moon shade, contact shadows and promoted fire shadow. Corgi rigid-part batching reuses the existing helper and preserves its animation pivots. Shared NPC navigation skips empty-bucket allocations and redundant convex-ground ray checks; crowd separation grounds the final X/Z position once, retaining special-move height ownership. These optimizations do not reduce population, dressing or effect caps.

The added native full-district stress remains a failing gate on low: roughly 6.2–6.3 ms simulation and 33.4–33.7 ms frame p95 at 4× CPU throttling. High and all pool/geometry/memory counters pass. E29 verification also encountered the existing WebKit audio smoke failure outside this lane, including a targeted retry. These failures are retained in the report; the lane is not claimed fully done against the requested performance/verification closure.
