## Revision after the first review

- Ashen horn: base moved from the top of the skull to its lower side and the horn now sweeps back and slightly down (was out and up, reading as a tall spike at the game camera). Height equals the base Mega (2.391 m Blender units).
- Ember: tusks are 1.6x larger and two bone-white back growths per side (mass colour) break the back silhouette. Depth grew +5% (1.65 vs 1.57 m), width unchanged; both stay inside the 1.3x Alpha footprint limit.

## Checks run

- `npm run assets:validate` for all new ids: no errors; triangles and file sizes within +10% of the base at every LOD.
- Scene Lab matrix, high and low, zoom 0.5/1/1.5, WebGPU and WebGL2: all new scenes pass (before the ember/ashen revision; the captures here are after it).
- `tests/e2e/alpha-look-budgets.spec.ts` (webgl/webgpu, high/low) and `tests/e2e/l10-alpha-scale.spec.ts` (high/low, zoom 1/0.5): 8/8 pass after the revision, one browser slot. The budget JSON in `docs/reports/alpha-look/budgets/` was rewritten by that run.
- Remote full `tests/unit`: 292 files pass (before the ember/ashen revision; `tests/unit/assets` rerun locally after it).

Known: a live scene with 8 Alphas in 5 looks drew 40 draw calls against 38 with the base only (one instanced batch per look on screen, none per Alpha).
