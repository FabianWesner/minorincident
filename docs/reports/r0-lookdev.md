# r0-lookdev — look tooling

Scope: extend the existing Tweakpane for deployed `?lookdev`, export validated look patches, capture V1–V6 at two tiers, and prepare independent review sheets/rubric. Palette asset migration belongs to r1-grade. No character assets, reference art, specifications or Bruno files were edited.

The production query loads L1 directly and shows the same panel used by dev `?debug`. Its 52 world-look fields and 120 palette swatches cover surface/nature colours, key/shadow/ambient/bounce, light direction and shadow controls, two-colour radial fog/ranges, bloom, tilt-shift start/end/repeats/amount, vignette, grass/foliage density and height, and wind strength. Stable renderer uniforms survive quality changes and level loads. Export downloads a minimal versioned JSON patch (including effective untouched A/B endpoints when editing legacy flat fog); invalid colours, unknown tokens, non-finite/out-of-bounds values and crossed ranges are rejected atomically. Reset restores authored defaults.

`npm run look:capture` builds production, uses an isolated preview (default 3306) or `LOOK_URL`, and captures seed 1 / tick 0 / paused simulation. Native-GPU headless Chromium is machine-locked; one game page is active at a time. Twelve originals (1600×900 high, 390×844 low) and six labelled sheets compare ours | mockup | Bruno PO without stretching reference images. The runtime measured 34.5 seconds initially and 37.8 seconds with live-uniform tooling, including build/preview/sheets. `npm run look:score` regenerates sheets, a rubric and blank JSON score template. Eight axes score each view/tier separately, with an explicit >=8 target and null for missing evidence. Motion cannot be scored from paused stills; an independent reviewer has not been run by this lane.

Usage and integration contract: `tools/look/README.md`. Current vertex-colour props still require r1-grade's shared-palette migration for every swatch edit to affect every L1 prop. `Materials.look.palette`, `Materials.texture`, and `GameView.look.nodes` provide its live hooks. Density is bounded by existing allocation (28/5 blades/m²); foliage density is a fraction of authored placements and height is a relative scale. Low tier keeps DOF off. WebGPU and physical phones remain manual checks.
