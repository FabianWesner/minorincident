# L6 frame hitch

The saved E24 phone run's 64.0 ms maximum (p50 13.6 ms, sample 119) was a cold shader compilation hitch: `WeatherView` selected the underground fog material graph after resident district, crowd and frozen-body shaders had already been warmed, invalidating that preparation; CDP/V8 profiling showed `getProgramParameter`/pipeline construction in the long gameplay task. Selecting weather before warm-up removed that path, but an isolated weather-only run still reached 52.5 ms; shader-owner marks identified five service-gate material programs first built around 10.74–10.82 seconds when a gate LOD entered the tunnel view (the nearby checkpoint capture took only 4.0 ms). The fix selects weather before warm-up and loads/warm-renders every quality-appropriate service-gate LOD through the existing registry cache before play, then removes the temporary hidden models. Three consecutive unchanged L6 specs under `E2E_SLOTS=1`, headless Metal WebGL, and both shared browser locks produced phone p50/max 13.9/35.3, 13.7/35.3 and 13.7/35.2 ms after merging main cfbbca51 as f0c3ba30; high maxima were 10.3, 14.6 and 10.1 ms, and all transition checks passed. All 1,497 frames from each existing tunnel measurement are retained in the evidence; no quality, crowd, effects, budgets or frame filters changed. Regression testing also exposed L1's first-use civilian LOD0 mesh bake; preparing its fixed cast before Begin removed 228.9/231.0 ms pickup/exit spikes (20.2/25.4 ms after), moving view loading from 5.4 to 8.7 seconds within the existing budget. L3's route endpoint now keeps its unchanged arrival tolerance inside the army zone, and L5's escort helper shoots visible grabbers immediately with the existing weapon; mission assertions are unchanged. Final validation passed typecheck, lint, build, 445 remote unit tests, all 19 L1–L5 phone/high perf cases, all 31 level browser checks (including continuity), and smoke (six unit plus 26 browser checks). Earlier `npm run verify -- E24` also passed remote simulations, 31 browser checks and four perf checks (phone max 36.1 ms). See `test-results/l6-hitch/evidence.json` for measurements and validation provenance.
