# s235 corn parting — work in progress

The corn-specific opacity fade and the shared player see-through cut were removed. The current shader uses a fixed set of mover uniforms and a one-second directional wake. The courier, corgi and driven car have reserved slots; other nearby infected and vehicles compete for twenty-one remaining slots, prioritized by distance with an incumbent bias. Replaced influences fade out before their slots can be reused. Corpses and building occlusion code were not changed.
