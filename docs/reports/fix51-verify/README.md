## Run

Run `npm run qa:accept -- --level L1` (L1–L10), or `--level all`. The default includes low/high native completion and stationary observations, controlled mechanics and edge cases, checkpoint deaths with an uninstrumented control, and headless physical WASD/mouse WebGL2 playthroughs. Global clauses are evaluated before each level's clauses. `--skip-browser` runs only native stages and preserves matching prior browser receipts; missing physical coverage remains open. `--reuse` requires matching source and stage hashes. `--tier low|high` and `--policy complete|stationary` narrow a diagnostic run and cannot alone qualify both qualities. Reports update atomically. Exit1 means FAIL/error; exit2 means incomplete; exit0 means all reported rows qualify.

The command writes the level JSON, [global.json](global.json) and [acceptance tracker](../../qa/acceptance-status.md). Each row retains the unchanged absolute target, every clause's value/status, source and observer hashes, receipt paths, historical finding, and next check.
