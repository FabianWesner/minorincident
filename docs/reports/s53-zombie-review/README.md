## Capture method and interpretation

Captures used a single headless Scene Lab browser under `tools/e2e-lock.sh`, ports 4947/4948, WebGPU/high quality and the real game camera. L4 daylight and documented blackout `night` were used for L4 roles; zoo uses `L8-zoo` and Mega uses `L10-night`. Fixtures use a neutral slab, not campaign practical-light placement. Zoom 1.5 is the farther view in this camera implementation.

Idle views show all four zoom/preset combinations. Full motion matrices retain those combinations at every sampled tick. Consolidated sheets select representative motion cells and label frame numbers; a label is not proof of a distinct attack/hit clip. Receipt clip/state audits govern that distinction.

Ordinary fixture dressing originally substituted civilian appearances; those initial captures were rejected. The verified motion fixture protects explicit infected appearance during dressing, initializes chase target/cooldown, then uses the production locomotion/combat system. Render identities were checked. Mega uses an Alpha fixture controller and does not validate its production pursuit controller. Static retired figures are manifest props because the current crowd path does not render those legacy bodies. The corpse GLB was supplied by a review-only network fixture, with borrowed template scale/orientation; native placement is not claimed.

Visual motion findings: generic raised-arm attacks and stiff hit gestures add little role personality. Alpha variants share broad hunched masses and nearly identical folded corpses. Zebra corpse folds into a contorted striped heap; gorilla corpse remains near upright and curled, lowering both to 3 day / 2 night. Dog loses facial/coat identity at distance. Mega has the strongest massing, but mottled surfaces and dark facial cavities remain below the bar. Night commonly collapses face, garment and limb separation.
