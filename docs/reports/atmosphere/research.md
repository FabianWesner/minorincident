## Techniques researched

- **Distance and height haze:** Three's [Fog](https://threejs.org/docs/pages/Fog.html) exposes linear near/far distance fog. The local PaletteMaterial already combines range fog with radial sky colors and weather height fog that clears near the hero. Changing its colors costs no new texture fetch, draw or pass; keep fog starts beyond action and the 150 m crossing sight line. The [volumetric fog example](https://threejs.org/examples/webgpu_postprocessing_fog.html) uses depth reconstruction and filtering; unnecessary for these targeted changes.
- **Per-level color grading:** [Lut3DNode](https://threejs.org/docs/pages/Lut3DNode.html) grades an input through a LUT texture. A new LUT is possible but adds sampling/assets and can distort courier red/teal and emissive eyes. Use the existing sun/shadow/sky/ground color split and shared look uniforms as an analytic grade, with no new post pass or global desaturation. Profile changes must rebase defaults without overwriting explicit lookdev edits or replacing uniforms.
- **Shafts:** [GodraysNode](https://threejs.org/docs/pages/GodraysNode.html) raymarches screen space (default 60 steps), needs shadow inputs and recommends blur/depth-aware compositing. Reject this cost for both tiers here. Existing WeatherView golden shafts and practical cone meshes already provide shafts; extra unoccluded mesh cards can spill across facades and obscure a top-down character.
- **Lamp glow and pools:** Existing emissive HDR/bloom + light field + depth-faded practical cones already implement the cheap approach. Tune existing bloom weights and add only 24 insect triangles at up to six powered outdoor lamps on high. No extra lights, shadows, framebuffer or particle simulation. Low omits the swarm.
- **Vignette and grain:** A restrained vignette in the existing final composite retains street edges. Grain rejected: screen noise competes with tiny enemy eyes and silhouettes, and temporal noise would make deterministic review harder.
- **Wet streets/reflections:** The existing wetness mask, environment map and light reflection splats are available on both tiers. Reject forcing rain/wetness into the story: E28 and L8–L10 specify dry weather. SSR remains deferred; no reflection render is added.
- **Rain/ash, clouds, sky:** Reuse existing GPU weather particles/cloud response, authored weather timelines and sky gradient. Add sparse daylight dust/birds/paper through the existing AmbientLife draw path rather than duplicate rain/ash pools. No weather simulation, sight or traction modifiers change.

Cost hypotheses are structural, not milliseconds: all palette/post edits reuse existing uniform operations; ambient motion adds up to three tiny draws in previously static daylight levels; insects add at most one draw/24 triangles on high and zero on low. Scene Lab must establish counters/readability. E18 native p95 cannot be certified before the permitted quiet timing window (06:00, or orchestrator authorization).
