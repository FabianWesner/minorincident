# Evidence notes

`archive-index.json` maps local measurement JSON and selected PNG captures to original paths and SHA-256 hashes. The repository commits JSON summaries/manifests and reports; full traces and images remain local under the evidence policy in `.gitignore`. `measurements.json` contains the retained numeric evidence; original walk traces contain all 3,600 frames.

The final inventory uses matching authored decay/LOD documents. The local `inventory-before.json` is a historical scan after the first twelve dead-socket renames; it is not the pristine starting inventory. `inventory-final.json` is authoritative for the reported final counts. Missing authored sources are unresolved, not invented reference failures.

`nearest-pixel-diagnostic.json` is a rejected calibration: nearest-pixel sampling on textured asphalt exceeded 15% through raster aliasing. The binding walk measurement uses bilinear linear luminance at fixed projected world pool centres. Raw full-image beam band gradients and beam-isolated differences are both retained; only the written full-image threshold controls the AC09 verdict.

The local `details-high/measurements.json` includes a mirrored-car proxy. It is not a genuine SSR ID pass and is excluded from AC10 acceptance. The renderer has no SSR pass. It also includes final car-only material controls, constrained to actual draw indices because static props share a vertex arena.

The native capture setup is documented in the report and `tools/qa/e25-spot-audit.ts`. Earlier NPC/health-bar movement differences remain in historical comparisons. The corrected school-bus L5 capture pauses clock reset/resume during loading and compares all image pixels, with both worlds at tick 0. No actor or region is masked out for accepted-look identity.

Failure logs are retained with their input stage named. They do not supersede the final gate receipt. The first remote freshness failures came from missing Git HEAD objects, then a snapshot missing public assets; the guarded remote wrapper supplies the full synced source/public snapshot without changing any test assertion. The subsequent navigation/L4-contact timeouts are retained as failures under concurrent CPU load. The final two-worker gate passed every active test, without increasing any time limit.

`sim-after.json` encodes every startup emissive/on sample with lossless run-length intervals (`statesRLE`), plus the complete interaction, breakage and sight-range results. The raw trace hash is in the artifact manifest.
