# bld.police

Legacy compatibility ID, aliasOf=bld.police-station. References inspected: both police references in the main checkout. This wrapper derives all three GLBs from the sole canonical station design, preserving the existing D-CIVIC caller's 10 × 5 × 8 m dimensions and origin. Separate compatibility files are necessary: sharing the larger canonical GLB changed the legacy layout collider/AABB contract. The explicit Blender assembly scale is (10/12,8/16,5/6.85); sourceScale stays absent so the production tool never scales it again. Semantic owners, door pivot and every socket retain the corresponding transformed position. Use bld.police-station for new L3 placement. The legacy silhouette is narrower than the hero due to the original caller footprint. No second building recipe or competing design is introduced.
