# int.metro-exit

Northgate platform, stairs, a dead escalator and the closing exit gate. Front/+X faces the platform approach, so the mandatory 45° camera sees the stair faces. Night egress runs toward -X, up to 3.5 m. The stairs and escalator are separate 1.5/1.35 m climbing routes. The escalator has no motor animation. Static header carries fictional NORTHGATE signage; no real trademarks. Gate is a single uiDark moving draw; its 2.0 m collider is attached to the hinge and follows its state. Level lane applies gate angle, arrival path and night preset. Stair columns have authored cuboid proxies, one per tread, in every tier.

Source reference inspected visually: `/Users/wesner/Workspace/minorincident/assets/int.metro-exit/reference-upscaled.png`. Uses sslib.fairhaven (reviewed authoring, batching, deterministic vertex AO and export); follows rescue_assets.py rigid-owner conventions. No decimation, no new dependencies or textures. Metres; glTF Y=0 is ground; no sourceScale correction. Measured tolerance is 3%, with identical AABBs across all three tiers.

## Delivery

Explicit tier recipes retain all openings, stairs, silhouette, semantic empties, light mounts and motion pivots. LOD1 omits bevels/fine trim; LOD2 also reduces radial sides, tread/sleeper density and small controls. Closed solids replace no outlines through triangle collapse. Static meshes are merged by palette and rigid owner; emissive refs survive as body_emi_* batches.

Main/emergency fixtures export valid ss_light records; strips use metro-main and fluorescent flicker, emergency lamps use metro-emergency. Fixed root physics includes mass=0, friction=.8, restitution=.05, pushable=false, kickable=false and stone impact sounds. col:* proxies are empties. District placement, switching, sounds, NPC routines, mission logic and independent prop gates are external interfaces.

Lamp mounts and stable body_emi_* references are declared in the manifest and checked in the production tiers. Runtime light/physics tables are generated by the existing extractors; only these four IDs change. The animated exit gate collider is local to its hinge: door consumers must apply that node transform/state; a fixed baked AABB is not a replacement for the moving collider.
