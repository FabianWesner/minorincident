# prop.hedge

Own round-3 trunk/twigs and smooth preview/collision proxy. Crown empties define runtime 80/40-card foliage; proxies are excluded from district draws. Original procedural leaf SDF, no Bruno textures.

Proxy previews use foliageDark/foliageLight palette tokens. Runtime crowns sample the live world palette and respect lookdev density, height and wind controls. Collision is regenerated from the delivered GLBs.
