# Quarantine gantry

Original 12.75 m wide, 7 m tall road gantry, with raised lettering on the +X face. Source is `build.py`; rebuild with `python3 tools/blender/run.py assets/prop.l10-quarantine-gantry/build.py` and pack with `npm run assets:pack -- prop.l10-quarantine-gantry`. The placement is decorative and does not add a solid road-wide collider. Gate posts, warning effigies and animated elements require further work.
