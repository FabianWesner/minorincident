# bld.gym

Roofed exterior assembled from the accepted `int.gym-cafeteria/model*.glb` in headless Blender. The charcoal roof membrane and warm cream coping follow the neighbouring flat-roof shops. A separately owned `roof` contains 36 triangles across all three supplied LODs within the unchanged original caps; existing interior geometry, joints, footprint and sockets are preserved; the lid rises 9.5 cm above the old coping within the declared height tolerance. Runtime cutaway hides this roof only when the courier is inside this placement.
