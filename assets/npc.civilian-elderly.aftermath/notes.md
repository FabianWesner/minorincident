# Okafor-compatible stock skin

Derived from `npc.civilian-elderly/build.py`, preserving its fifteen rigid animation owners, native joint hierarchy, cane, glasses, cap, argyle vest and weapon/backpack sockets. The shared source adapter runs the native shape/rig section with explicit primitive recipes; it never runs the base finishing decimation. Applied metres conversion matches the shipped base (1.27233734 once).

Broad feathered soot on vest/shirt/trousers; clean pale left forearm wrap is batched into `foreArmL`. This is a living unarmed adult, with the base character contract rather than prop physics. Runtime casting, following, injury poses and lighting are separate interfaces. `front` marks +X.
